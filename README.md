# 🎯 Jogo Click Rápido\!

Um jogo de navegador simples, divertido e viciante, desenvolvido para testar sua agilidade e precisão. O objetivo é clicar no quadrado azul o máximo de vezes possível em 30 segundos, evitando o quadrado vermelho.

-----

## 🚀 Como Jogar

1.  **Inicie o Jogo:** Abra o arquivo `index.html` em qualquer navegador moderno.
2.  **Clique em "Iniciar Jogo"**: O cronômetro de 30 segundos começará a contagem regressiva.
3.  **Marque Pontos**: Clique no **quadrado azul** para marcar um ponto. A cada clique, os quadrados mudarão de posição.
4.  **Evite a Armadilha**: Se você clicar no **quadrado vermelho**, o jogo termina instantaneamente.
5.  **Bata seu Recorde**: Tente fazer a maior pontuação possível antes que o tempo acabe\!

-----

## ✨ Funcionalidades

  * **Contador de Pontos**: Acompanhe sua pontuação em tempo real.
  * **Timer Regressivo**: O jogo tem uma duração fixa de 30 segundos, adicionando um desafio de velocidade.
  * **Posicionamento Aleatório**: Os alvos aparecem em locais aleatórios na área de jogo, tornando cada partida única.
  * **Design Responsivo**: Interface que se adapta a diferentes tamanhos de tela, de desktops a dispositivos móveis.
  * **Feedback Visual Imediato**: Efeitos de `hover` e clique nos elementos para uma experiência mais interativa.
  * **Interface Moderna**: Um design limpo e agradável com gradientes, sombras e tipografia estilizada.

-----

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias web fundamentais:

  * **HTML5**: Para a estrutura e semântica do conteúdo.
  * **CSS3**: Para estilização, layout responsivo (com Flexbox), animações e uso de variáveis CSS para um design consistente.
  * **JavaScript (ES6+)**: Para toda a lógica do jogo, manipulação do DOM e interatividade.

## 🏃‍♀️ Como Executar o Projeto Localmente

Por ser um projeto web estático, não há necessidade de instalação de dependências ou servidores complexos.

1.  Faça o clone ou o download deste repositório.
2.  Navegue até a pasta do projeto.
3.  Abra o arquivo `index.html` diretamente no seu navegador de preferência (Google Chrome, Firefox, etc.).

E pronto\! O jogo estará funcionando.
